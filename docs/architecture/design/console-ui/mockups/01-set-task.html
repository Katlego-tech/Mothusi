What happens next

  1. The Setter sits the test and compares its answers with your memo. A line it doubts stops the run and asks you before a single script is marked.
  2. The Marker marks every script against the memo, quoting the words that earned each mark and the memo line it applied.
  3. Code checks every total, maximum and quote, the PoA weighting and the cognitive grid. A failed check sends the script back with the reason; after three attempts it comes to you.
  4. The Moderator re-marks a blind sample: 10% of the class, at least 6 scripts, top, middle and bottom, without seeing the first marks. Disagreements go back with the reason written down.
  5. You approve the paperwork: mark sheet, item analysis, catch-up plan, a note per learner, the moderation report. Only then are files written and notes sent.

Nothing goes to a learner or a parent until you approve it.
